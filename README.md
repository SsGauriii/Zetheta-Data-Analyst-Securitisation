# Zetheta-Data-Analyst-Securitisation
Data Analyst Securitisation project completed as part of the Zetheta Algorithms Data Analyst role.

## Project Overview

This project was completed as part of the Data Analyst – Securitisation project at Zetheta Algorithms Private Limited.

The project focuses on analysing loan portfolio performance and creating an interactive Power BI dashboard for monitoring key securitisation and credit-risk indicators.

## Tools Used

- Microsoft Power BI
- DAX
- Data Analysis
- Data Visualization
- Financial Risk Analysis

## Data Sources

The analysis uses multiple datasets covering:

- Loan-level securitisation data
- DPD snapshot history
- Monthly pool loss performance
- Static pool vintage performance

## Key KPIs

The dashboard includes:

- Total Loan Balance
- Total Loans
- Average Loan Balance
- Delinquent Loans
- Delinquency Rate
- Written-Off Loans
- Write-Off Rate

## Dashboard Analysis

The dashboard contains visualisations for:

- DPD Bucket Distribution
- Monthly Net Loss Trend
- Loan Balance by Servicer
- Delinquent Loans by Servicer
- IFRS 9 Stage Distribution
- Vintage Cumulative Loss Rate
- Monthly Net Loss Rate
- 30+ DPD by Months on Book

## Interactive Filters

The dashboard includes slicers for:

- Servicer
- Pool ID

These allow users to analyse portfolio performance for different segments.

## DAX Measures

Key DAX measures were created for portfolio and delinquency analysis, including:

- Total Loan Balance
- Total Loans
- Average Loan Balance
- Delinquent Loans
- Delinquency Rate
- Written Off Loans
- Write-Off Rate

## Project Outcome

The project provided practical experience in analysing financial data, creating DAX measures, developing Power BI dashboards, and presenting risk-related business insights through data visualisation.
